Este projeto foi desenvolvido como o primeiro desafio prático do curso Formação HTML da DIO (Digital Innovation One). O objetivo principal foi aplicar os conceitos iniciais de marcação de hipertexto, focando na estruturação de conteúdo e no uso semântico de tags.

Objetivos do Projeto
O site foi estruturado para explicar o funcionamento básico da internet, abordando o modelo Cliente-Servidor e os fundamentos da linguagem HTML (HyperText Markup Language - Linguagem de Marcação de Hipertexto).

Elementos Utilizados
Para demonstrar o domínio sobre o conteúdo das aulas, o código incorpora as seguintes ferramentas:

Hierarquia e Blocos de Texto: Organização de títulos do <h1> ao <h6>, parágrafos (<p>), divisores horizontais (<hr>) e citações formatadas (<blockquote>).

Estilização de Texto: Aplicação de destaques com negrito (<strong>), itálico (<i>), sublinhado (<u>), marca-texto (<mark>) e letras menores (<small>).

Listas e Navegação: Construção de listas ordenadas (<ol>) e não ordenadas (<ul>), além de links externos (<a>) para referências.

Tags Técnicas e Específicas:

<sub> e <sup>: Para textos subscritos (fórmulas) e sobrescritos (potência).

<del>: Para indicar informações removidas ou corrigidas.

<abbr>: Para definir o significado de siglas e abreviações.

<font>: Utilizada exclusivamente para entender a evolução das tags legadas frente ao uso moderno do CSS (Cascading Style Sheets - Folhas de Estilo em Cascata).
