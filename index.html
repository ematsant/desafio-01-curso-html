A Estrutura da Internet e da Web

Entendendo o Modelo Cliente-Servidor

A comunicação na internet funciona com base em quem pede e quem entrega. O cliente é quem faz a requisição inicial, e o servidor é quem processa e responde.

O que são Servidores?

Um servidor é apenas um computador comum de casa é, na verdade, uma máquina potente projetada para ficar ligada o tempo todo. Ele armazena arquivos e sites. É importante notar que sem servidores, o conteúdo não fica disponível online.

O que são Clientes?

O cliente é o dispositivo ou programa que pede a informação para o servidor. Existem vários exemplos no nosso dia a dia:

  • Navegadores web (como Chrome ou Edge)
  • Aplicativos de redes sociais no celular
  • Jogos online rodando no computador
Como a comunicação acontece?
  1. O cliente solicita uma página usando uma URL (Uniform Resource Locator - Localizador Padrão de Recursos).
  2. O pedido viaja pela rede através do protocolo HTTP (Hypertext Transfer Protocol - Protocolo de Transferência de Hipertexto).
  3. O servidor procura a página e envia os dados de volta para o cliente.

Agora que entendo como a web funciona, estou aprendendo HTML (HyperText Markup Language - Linguagem de Marcação de Hipertexto). O HTML usa tags para dar a estrutura da página.
